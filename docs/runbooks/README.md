# Runbooks

Guides to set up or operate the project.

- Naming: `<verb>-<object>.md`, for example `restore-postgres.md`.
- Template: Purpose, Prerequisites, numbered Steps, Verify, Troubleshooting.
- Rule: commands must be runnable and the doc must end its steps with a Verify step.
