# Decisions

Architecture decision records (ADRs).

- Naming: `ADR-NNN-<kebab-title>.md` with a 3-digit number that is never reused. This `README.md` is not an ADR.
- Template: Status/Date/Supersedes, Context, Decision, Consequences.
- Rule: refine an ADR by updating it in place; a reversed decision gets a new ADR with `Supersedes: ADR-NNN`.
